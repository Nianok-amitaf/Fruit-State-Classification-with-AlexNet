# Fruit State Classification with AlexNet

A deep learning project that classifies the **state of a fruit** from an image using an **AlexNet** model.
This project uses a convolutional neural network (AlexNet) to analyse images of fruit and classify their state.
## Method
1. Image preprocessing (resize, normalisation, augmentation if used)
2. AlexNet model
3. Training and evaluation

| Accuracy | 90% |
